

# 🐦 Flappy Bird Game in Java 🎮

A nostalgic recreation of the classic **Flappy Bird** game — built completely from scratch using **Java** and **Swing**! Simple, addictive, and just as rage-inducing as you remember. 🕹️💥

## 🚀 Features

🎮 **Classic Flappy Bird Mechanics**  
Tap or press to flap and navigate through pipes!

🎨 **Custom Graphics**  
Designed using Java's Swing and AWT libraries.

🧠 **Simple Game Logic**  
Clean and easy-to-understand code – perfect for Java beginners.

📈 **Score Tracker**  
Tracks and displays your current score and high score.

🔁 **Replay Support**  
Crash? No worries — restart and try again instantly!

---

## 🛠️ Built With

- ☕ **Java SE**
- 🎨 `javax.swing`, `java.awt` – for UI and game rendering
- 🕹️ Object-oriented design – for game logic and modularity

---

📂 flappy-bird-java/

├── FlappyBird.java       # Main game class

├── Renderer.java         # Handles drawing the game objects

├── Pipe.java             # Obstacle logic

├── Bird.java             # Player (flappy bird) logic

└── assets/               # Optional folder for images/sounds

## 🎮 Controls

| Action              | Key        |
|---------------------|------------|
| Flap                | SPACEBAR   |
| Restart after crash | R          |
| Quit game           | ESC        |
